### Existing shared surfaces

- SHELL-01: [CRM layout](../../app/(crm)/layout.tsx) redirects missing authorization to /login, loads active user/organization, and filters navigation by module permission; billing/payments use separate policy predicates. [Navigation definitions](../../src/components/layout/navigation.ts) and [shell](../../src/components/layout/crm-shell.tsx) implement desktop collapse (localStorage vra-sidebar-collapsed and storage/custom events), mobile drawer open/close, active links, account/sign-out, theme toggle, sticky header slot and route history. Mobile overlays/keyboard and toast states are separate review surfaces.
- AUTH-01: [Login](../../src/features/auth/components/login-form.tsx), [password forms](../../src/features/auth/components/password-forms.tsx), [sign out](../../src/features/auth/components/sign-out-button.tsx): credential submit, pending/error/success, forgotten/reset password navigation, token failures, and logout redirect. Password changes on account use the auth client; they are not additional CRM Server Actions. API auth configuration/disabled capabilities are in [API inventory](API_ENDPOINT_INVENTORY.md).
- OCR-01: [/ocr-reader](../../app/ocr-reader/page.tsx) renders no visual UI. Same-origin parent-only postMessage accepts numeric ID + Blob, invokes recognizeText, returns text/error; sends ready and removes listener on unmount. [read-id.ts](../../src/features/contacts/lib/read-id.ts) opens a hidden iframe, verifies source/origin, correlates requests and has a 30-second startup timeout. [ID camera](../../src/features/contacts/components/id-camera-capture.tsx) adds camera permission/error/capture/retake/close states; [contact form](../../src/features/contacts/components/contact-form.tsx) handles ID type selection, file/camera/OCR preview/checks and locked fieldset before required document checks. Do not count the hidden frame as a normal interactive page.
- LEGAL-01: [privacy](../../app/privacy/page.tsx) and [terms](../../app/terms/page.tsx) are public legal content/routes with navigation links; these are content/link checks, not CRUD operations. [Root](../../app/page.tsx) is a redirect surface; see route table for source.
- STATE-01: authorization denial routes to [/forbidden](../../app/(crm)/forbidden/page.tsx); record pages can call notFound; lists provide no-record/no-match states; forms disable controls during pending work and surface action errors/success via inline state or toast. Conditional controls remain guarded by server policy. [Global error](../../app/global-error.tsx) offers Try again via retry; module error/loading surfaces are enumerated below.
- LIST-01: controls include query-backed FilterForm, reset/clear and pagination links plus client sort/page-size controls where present. [FilterForm](../../src/components/common/filter-form.tsx), [table pagination](../../src/components/ui/table-pagination.tsx), [paginator](../../src/components/ui/paginator.tsx), [row action menu](../../src/components/ui/row-actions-menu.tsx), [form navigation](../../src/components/common/form-navigation.tsx), and [cover image field](../../src/components/ui/cover-image-field.tsx) contain reusable change/click/navigation/upload handlers. See control register for literal field names, labels, filters, pagination and event bindings; prop-driven controls list their expressions rather than invented fixed values.
